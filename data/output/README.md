# Sentinel Vision AI — Output Records Directory

This directory stores the incident logs produced by Sentinel Vision AI.

## Files & Classification

- **`simulation_incident_records.jsonl`**:
  > **DISCLAIMER**: This file was generated by running `demo_simulation.py` as an offline software simulation / logic verification test. It proves the spatial point-in-polygon containment, ground footprint calculation, state transitions (`OUTSIDE` -> `ENTRY` -> `OCCUPANCY` -> `EXIT`), and schema compliance. **This is NOT real GPU inference.**

- **`incident_records.jsonl`**:
  Target destination for live DeepStream perception events emitted during real video pipeline execution via `launch_demo.py` or `src/sentinel_pipeline.py`.
